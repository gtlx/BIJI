# Biji Note

跨平台笔记编辑器，支持插件系统、知识图谱、云同步、离线功能。

## 功能特性

### 核心功能
- **双向链接** - 使用 `[[笔记标题]]` 语法创建笔记间链接
- **知识图谱** - 可视化展示笔记间的关联关系
- **SQLite 数据库** - 高效、可靠的本地数据存储
- **Markdown 编辑** - 实时预览、编辑、预览三种模式

### 插件系统
- 模块化插件架构
- 标准化的插件接口
- 插件管理（安装、卸载、启用/禁用）
- 权限控制确保安全性
- 插件功能与主程序集成

### 编辑器
- 模式切换：富文本 / Markdown
- Markdown 预览模式：实时预览 / 编辑模式 / 预览模式
- 笔记模板：空白笔记，会议记录、每日日志、待办清单
- 自动保存

#### 顶部菜单栏

应用原生菜单栏，包含以下菜单：

- **文件**
  - 新建笔记 (Ctrl+N)
  - 新建文件夹 (Ctrl+Shift+N)
  - 导入 / 导出
  - 版本控制
  - 发布网站
  - 设置 (Ctrl+,)
  - 退出 (Ctrl+Q)

- **编辑**
  - 撤销 / 重做
  - 剪切 / 复制 / 粘贴
  - 查找 (Ctrl+F)

- **视图**
  - 暗黑模式
  - 放大 / 缩小 / 重置缩放
  - 全屏 (F11)
  - 开发者工具 (F12)

- **插件**
  - 插件管理
  - 插件市场

- **帮助**
  - 关于
  - 反馈

#### 侧边栏与工具栏

- **左侧边栏**
  - 可折叠/展开（快捷键 Ctrl+B）
  - 顶部按钮区：文件、搜索等（支持拖动排序、显示/隐藏）
  - 文件夹导航（支持面包屑）
  - 新建笔记/文件夹按钮
  - 按钮可在左右侧边栏之间移动

- **工具栏 (class="toolbar")**
  - 屏幕左侧的浮动垂直工具栏
  - 包含：图谱切换、导出、插件按钮
  - 图谱按钮：切换知识图谱视图
  - 导出按钮：导出笔记为 Markdown
  - 插件按钮：显示已启用的插件

- **中间区域**
  - 笔记列表：显示当前文件夹下的所有笔记
  - 编辑器：Markdown 编辑，支持实时预览
  - 知识图谱：可视化展示所有笔记和链接关系
  - 状态栏：底部，显示同步状态、字数统计等

- **右侧边栏**
  - 可折叠/展开
  - 顶部按钮区：大纲等（可从左侧移动）
  - 大纲：显示当前笔记的标题结构
  - 点击标题可跳转到对应位置

#### 知识图谱

- 显示所有笔记作为节点
- 笔记间的 `[[链接]]` 显示为边
- 疏密调节：控制节点间距（0-100）
- 居中/刷新按钮
- 显示统计：笔记数、链接数、总字数
- 点击节点可跳转到对应笔记

- **Hugo** - 快速、灵活的静态网站生成器
- **Astro** - 现代静态站点构建工具
- **VitePress** - Vue 驱动的静态网站生成器

发布功能：
- 一键将笔记发布为静态网站
- 自动生成导航和侧边栏
- 支持自定义站点名称和基础 URL

### 优势

1. **中文原生支持** - 开箱即用的中文界面
2. **SQLite 高效** - 查询性能优于文件存储
3. **轻量级** - 代码量小，易于理解和二次开发
4. **插件系统** - 可扩展性强

### 劣势

1. **功能较少** - 缺少块引用等高级功能
2. **无移动端** - 只有桌面版
3. **插件生态薄弱** - 无插件市场
4. **同步功能不完善** - WebDAV 未实现

### 改进方向

1. **短期** - 完善同步功能，支持 WebDAV
2. **中期** - 实现块引用，参考 Logseq
3. **长期** - 开发移动端，建立插件生态

## 数据存储

笔记数据存储在 SQLite 数据库中：
- **路径**: `~/.config/biji-note/biji.db` (Linux)
- **表结构**:
  - `notes`: 笔记内容
  - `folders`: 文件夹
  - `links`: 笔记链接
  - `settings`: 应用设置
